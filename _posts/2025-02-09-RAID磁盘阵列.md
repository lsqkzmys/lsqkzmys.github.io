**磁盘阵列：**即为了提高安全性和使用效率，使用多块磁盘并成一个阵列一起使用。

### <span style="color:#3498db">常见的磁盘阵列</span>

- **<span style="color:#27ae60">RAID0</span>**：至少需要两块磁盘。空间利用100%。将数据拆分写入两块磁盘，读写速度最快，但没有冗余，适合临时缓存等一些需要快速处理，不怎么重要的数据的处理

- **<span style="color:#27ae60">RAID1</span>**：至少需要两块磁盘。空间利用50%。将相同的数据同时写入两块磁盘，这样当一块磁盘坏掉后，另一块盘也可以恢复数据。安全性好，但是成本大，适合存储一些重要的数据。

- **<span style="color:#27ae60">RAID5</span>**：至少需要三块磁盘。空间利用n-1/n。使用奇偶校验存储数据，有一块盘的冗余。兼顾空间和成本，有一定的安全性。但是也只能容许一块盘失效，重建复杂。

- **<span style="color:#27ae60">RAID10</span>**：至少需要四块磁盘。空间利用50%。兼顾了RAID0和RAID1的优点，读取速度快的同时，安全性也很好，但成本最高。适合存储数据库，服务器等重要数据

#### <span style="color:#3498db">第二步：安装工具并创建磁盘阵列</span>

未安装工具可使用这条命令：`sudo apt update && sudo apt install mdadm`

**创建阵列并挂载使用：** 

```bash
sudo mdadm --create /dev/md55 --level=5 --raid-devices=3 /dev/sdc /dev/sdd /dev/sde
# 想再添加热备盘用 --spare-devices=1 /dev/sdf
sudo mdadm --detail /dev/md55  # 查看阵列详情
sudo mdadm --detail --scan | sudo tee -a /etc/mdadm.conf # 阵列挂载持久化，否则重启后需要手动执行mdadm --assemble /dev/md5555
sudo mkfs.ext4 /dev/md55 # 初始化文件系统
sudo mount /dev/md55 /data1 #挂载
sudo echo "UUID=$(blkid -s UUID -o value /dev/md55) /data1 ext4 defaults 0 0" | sudo tee -a /etc/fstab
# 持久化挂载
```

#### <span style="color:#3498db">磁盘阵列的删除</span>

```bash
sudo vim /etc/fstab # 进入其中，取消md55文件开机自动挂载
sudo vim /etc/mdadm.conf # 进入其中，取消md55阵列开机自动挂载
sudo umount /data1 #取消文件系统挂载
sudo mdadm --stop /dev/md55 # 停止阵列运行
sudo mdadm --zero-superblock /dev/sdc # 擦除磁盘头部 mdadm 阵列信息，系统不再识别这块盘属于 RAID
sudo mdadm --zero-superblock /dev/sdd
sudo mdadm --zero-superblock /dev/sde
```
