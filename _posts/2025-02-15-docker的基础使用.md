## **<span style="color:#3498db">docker是什么？</span>**

**<span style="color:#27ae60">是什么：</span>**docker是容器化工具，相当于配置好的应用直接拿来使用。

**相比普通的虚拟机使用，它有以下优点：**

1. 出于各种原因，在日常使用应用时，可能由于各种配置问题导致同样的命令有的应用能使用，有的就不行，而使用docker镜像启动的容器，其配置都与镜像一致，不会出现配置不一的问题

2. 虚拟机在配置初期就需要一篇完整的大空间，而docker则是使用多少，就占多少

3. 虚拟机需要配置完整的内核，而容器则与宿主机共用一套内核

## **<span style="color:#3498db">docker的安装</span>**

**第一种：通过网站安装**

```bash
# 下载:
curl -fsSL https://get.docker.com | bash -s docker --mirror Aliyun 
# 2 开机自启 
sudo systemctl enable docker
 # 3 启动 
sudo systemctl start docker
```

**第二种：通过apt安装**

```bash
sudo apt install docker.io docker-compose-v2 -y

sudo systemctl enable --now docker

#如果docker compose安不了
sudo mkdir -p /usr/local/lib/docker/cli-plugins
curl -SL https://github.com/docker/compose/releases/latest/download/docker-compose-linux-x86_64 -o /usr/local/lib/docker/cli-plugins/docker-compose
chmod +x /usr/local/lib/docker/cli-plugins/docker-compose
```

**不论哪种方法都要将用户加入docker组，不然没有权限**

```bash
# 如果没有docker组，记得添加
newgrp docker

# 将用户加入docker组
sudo usermod -aG docker $USER

```

## **<span style="color:#3498db">docker的一些重要概念</span>**

1. **镜像（image）：**只读模板，相当于安装包 / 快照。比如 `nginx:alpine`，存放程序、依赖、配置。镜像不能修改。

2. **容器 (container)：**镜像运行起来的实例。一个镜像可以启动 N 个容器；容器读写层，删除容器数据丢失（除非挂载卷）

3. **Dockerfile：** 构建镜像的脚本文件，文本，写指令，`docker build`生成镜像

4. **仓库 (Registry)：**存放镜像的地方，官方公共仓库 Docker Hub，也可以自建私有仓库。

5. **卷（Volume）：**数据持久化。容器删除内部数据就没了，卷把数据挂载到宿主机，实现数据保存

6. **Docker Compose:**多容器编排工具，一个 yaml 文件定义多个容器，一键启停

## **<span style="color:#3498db">docker常用命令</span>**

```bash
# 拉取镜像
docker pull nginx:latest

# 删除镜像
docker rmi nginx:latest

# 查看已有镜像
docker images

# 依据指定镜像启动容器 -d 后台启动 -p 端口映射，容器端口:宿主机端口 --name 指定容器名字
docker run -d -p 80:8080 --name mynginx nginx:latest

# 查看正在运行的容器
docker ps

# 查看所有容器
docker ps -a

# 停止容器
docker stop mynginx

# 启动容器
docker start mynginx

# 删除容器
docker rm mynginx

# 列出数据卷
docker volume ls

# 创建数据卷
docker volume create vol1

# 查看数据卷详情
docker volume inspect mydata

# docker 管理的卷默认路径：`/var/lib/docker/volumes/卷名/_data`

# 挂载数据卷
docker run -d -p 80:8080 --name mynginx -v vol1:/usr/share/nginx/html nginx:latest

# 挂载宿主机目录，目录必须**宿主机提前存在**，不会自动创建父目录
docker run -d -v /host/path:/container/path nginx

# 删除数据卷
docker volume rm mydata

# 删除容器，同时删除该容器关联的匿名卷/命名卷
docker rm -v nginx_demo

# 如果有compose.yaml这类批量操作容器的脚本，可以批量配置启动容器，-d后台运行
docker compose up -d

# 批量停止和再启动容器
docker compose stop/start

# 批量删除容器
docker compose down

# 清理停止的容器、无用网络、悬空镜像；不会删除数据卷
docker system prune

# 清理：停止容器、无用镜像、无用网络 + 未被任何容器使用的数据卷
docker system prune -a --volumes


```
