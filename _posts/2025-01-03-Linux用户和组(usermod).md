__在 Linux 多用户操作系统中，用户与用户组是权限体系的基础。所有文件、进程和资源的访问控制，最终都围绕 “用户” 和 “组” 展开。__

#### 一、用户管理核心命令 ####

1.__创建用户：useradd__

用于新建系统用户，默认会同时创建一个与用户名同名的主组。
常用参数：

-d 目录：指定用户家目录，默认 /home/用户名

-m：自动创建家目录（部分系统默认开启）

-M：不创建家目录

-s shell：指定登录 Shell，如 /bin/bash、/sbin/nologin

-u UID：手动指定用户 UID

-g 组名/组ID：指定用户的主组

-G 组1,组2：将用户加入多个附加组

-e 日期：设置账号过期时间，格式 YYYY-MM-DD

-r：创建系统用户（UID 通常小于 1000，无家目录）


2.__删除用户：userdel__

删除用户账号及相关数据。

常用参数：

-r：同时删除用户家目录和邮件目录

-f：强制删除，即使用户已登录


3.__修改用户属性：usermod__

修改已有用户的各项属性，参数与 useradd 大部分一致。

常用参数：

-l 新用户名：修改用户名

-d 新家目录：修改家目录路径，配合 -m 可移动旧目录内容

-s shell：修改登录 Shell

-g 主组：修改主组

-G 组列表：覆盖附加组列表

-aG 组列表：追加附加组（不覆盖原有）

-L：锁定用户账号

-U：解锁用户账号



4.__设置 / 修改密码：passwd__

设置或更新用户密码，普通用户只能修改自己的密码，root 可修改所有用户密码。

常用参数：

-l：锁定密码（等效于 usermod -L）

-u：解锁密码

-d：清空密码，使账号无密码即可登录

-e：强制用户下次登录时修改密码

-S：查看密码状态信息

示例：

```bash
useradd -m -s /bin/bash -G wheel alice

userdel -r alice

usermod -aG docker alice

passwd alice
```

5.__查看用户信息__

id 用户名：显示用户 UID、GID 及所属组

whoami：显示当前登录用户名

who：显示当前登录系统的用户列表

w：显示登录用户及正在执行的操作

last：查看用户最近登录记录


#### 二、用户组管理核心命令 ####

1.__创建用户组：groupadd__
新建用户组。

常用参数：

-g GID：指定组 ID

-r：创建系统组



2.__删除用户组：groupdel__

删除用户组。*注意：不能删除作为某用户主组的组，需先修改用户主组。*



3.__修改组属性：groupmod__

修改组名或 GID。

常用参数：

-g 新GID：修改组 ID

-n 新组名：修改组名


4.__组成员管理：gpasswd__

管理组内成员，比 usermod 更精细。

常用参数：

-a 用户名：将用户加入组

-d 用户名：将用户从组中移除

-A 用户列表：设置组管理员

-M 用户列表：批量设置组成员

示例：

```bash
groupadd devteam
groupdel devteam
groupmod -n backend devteam
gpasswd -a bob devteam
```

#### 三、核心配置文件详解 ####

1.__/etc/passwd__

用户信息文件，所有用户均可读取，每行对应一个用户，字段用冒号分隔。

格式：

```plaintext
用户名:密码占位符:UID:GID:用户说明:家目录:登录Shell
```
密码占位符固定为 x，真实密码存于 /etc/shadow

UID 0 为 root，1-999 通常为系统用户，1000+ 为普通用户

/sbin/nologin 表示禁止登录，常用于服务账号

2.__/etc/shadow__

用户密码文件，仅 root 可读，存储加密后的密码及密码策略。

格式：

```plaintext
用户名:加密密码:最后修改时间:最小修改间隔:密码有效期:警告天数:宽限天数:账号过期时间:保留
```

加密密码字段若为 !! 或 *，表示账号被锁定 / 无密码

时间单位均为天，以 1970-01-01 为起点

3.__/etc/group__

用户组信息文件，所有用户可读。

格式：

```plaintext
组名:组密码占位符:GID:组成员列表
```

组成员列表中，多个用户用逗号分隔

主组用户不会出现在此列表中，仅附加组成员会显示

4.__/etc/gshadow__

组密码文件，仅 root 可读，存储组管理员和组密码。

格式：

```plaintext
组名:加密密码:组管理员:组成员
```
