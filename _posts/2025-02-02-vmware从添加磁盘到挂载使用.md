## 总体思路

1. **直接分区挂载** 

        挂载磁盘 -> 创建分区 -> 创建文件系统 -> 挂载使用

2. **逻辑卷挂载**

        挂载磁盘 -> 创建分区 -> 分区格式化物理块 -> 合并或创建逻辑卷卷组 -> 创建逻辑卷 -> 创建文件系统 -> 挂载使用

**添加磁盘后查看**

虚拟机 -> 编辑虚拟机设置 -> 添加 -> 一直下一步到设置空间 -> 存储为单个文件方便管理

### 直接分区挂载

#### 一.创建gpt分区：

1. sudo parted /dev/sdb （进入parted交互式界面）
2. mklabel gpt （新建gpt分区表）
3. mkpart primary 0GB 3GB(从多少开始到结束，如果分区有3GB被占用了，就从3GB开始。p查看是否创建成功) 
4. q（退出）

![mm](/assets/img/2026-07-30-16-38-43.png)

#### 二.格式化文件系统及挂载：

1. sudo mkfs.ext4 /dev/sdb1(分区格式化文件系统)
2. sudo mkdir /data(创建挂载目录) 
3. sudo mount /dev/sdb1 /data(挂载分区到指定目录下) 
4. echo "UUID=$(blkid -s UUID -o value /dev/sdb1) /data ext4 defaults 0 0" | sudo tee -a /etc/fstab(持久化挂载) 
5. systemctl daemon-reload（重载）

### 逻辑卷挂载


#### 一.创建gpt分区：

1. sudo parted /dev/sdb （进入parted交互式界面）
2. mklabel gpt （新建gpt分区表）
3. mkpart primary 3GB 6GB(从多少开始到结束，分区已经有3GB被占用了，就从3GB开始。p查看是否创建成功) 
4. q（退出）

![mm](/assets/img/2026-07-30-17-20-17.png)

#### 二.物理块格式化，创建卷组，创建逻辑卷

1. sudo pvcreate /dev/sdb2(物理块格式化。查看用pvdisplay)
2. sudo vgcreate vg_data /dev/sdb2 （创建卷组。查看用vgdisplay）
3. sudo vgchange -a y vg_data(激活卷组)
4. sudo lvcreate -l  +100%FREE -n lv_exa vg_data (用卷组创建逻辑卷。查看用lvdisplay。这里的-l 后跟的块数，每块默认4MB，也可以+100%FREE。如果想创建指定大小用 -L 3G。-n后跟名字)
5. sudo mkfs.ext4 /dev/vg_data/lv_exa （为逻辑卷格式化文件系统）
6. sudo mkdir /data1(创建挂载目录) 
7. sudo mount /dev/vg_data/lv_exa /data1(挂载分区到指定目录下) 
8. `echo "UUID=$(blkid -s UUID -o value /dev/vg_data/lv_exa) /data1 ext4 defaults 0 0" | sudo tee -a /etc/fstab(持久化挂载) `
9. systemctl daemon-reload（重载）
