虚拟机扩容扩的只是空间的大小，分区和文件系统不受影响，而我们平时用的就是分区和文件系统。

所以在扩容后要对新增的扩容空间进行处理

## windows磁盘扩容

### 空间扩容操作步骤


1. 关闭虚拟机
2. 编辑虚拟机设置
3. 点击硬盘
4. 点击扩展
5. 选择扩展后容量，点击扩展

![mm](/assets/img/2026-07-30-10-25-33.png)


### 分区和文件系统扩容操作步骤

没装工具的话，windows自带的磁盘扩容，只允许向左边紧邻的空间扩容

win+x -> 磁盘管理 -> 右键未分配空间左边的空间（我这里是E盘） -> 扩展卷 -> 下一步 -> 选择要分配的空间(我这里全部分配了) -> 完成

## Linux磁盘扩容

### 空间扩容操作步骤

1. 关闭虚拟机
2. 编辑虚拟机设置
3. 点击硬盘
4. 点击扩展
5. 选择扩展后容量，点击扩展

![mm](/assets/img/2026-07-30-10-47-17.png)

### 分区和文件系统扩容操作步骤

因为默认扩容都是在最后，所以扩sda3

sudo parted -s /dev/sda resizepart 3 100%（让sd3识别所有新空间）->sudo partprobe /dev/sda（让系统重新识别sd3空间） ->  sudo pvresize /dev/sda3（重构sd3物理卷） -> sudo lvextend -l +100%FREE /dev/ubuntu-vg/ubuntu-lv （扩容逻辑卷）-> sudo resize2fs /dev/ubuntu-vg/ubuntu-lv （重构ext4文件系统）

xfs文件系统为：sudo xfs_growfs /dev/ubuntu-vg/ubuntu-lv
