### **<span style="color:#3498db">如果当前目录有Dockerfile配置文件，用配置文件提交</span>

 ```bash
 docker build
 ```

### **<span style="color:#3498db">从容器提交</span>** 

```bash
docker commit container_id my_image:tag
```

### **<span style="color:#3498db">save/load</span>**

```bash
docker save -o image.tar image_name
docker load -i image.tar
```

### **<span style="color:#3498db">export/import</span>**

```bash
docker export container_name > container.tar 
docker import container.tar my_image:tag
```
