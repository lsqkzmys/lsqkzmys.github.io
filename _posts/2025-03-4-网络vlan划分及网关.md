### **<span style="color:#3498db">前提：本篇相关网络设备皆为思科设备</span>**


### **<span style="color:#3498db">vlan的作用</span>**

**就像一家公司划分不同部门，VLAN 用来实现二层广播域隔离。同一个交换机上，划分不同 VLAN 后，广播帧只会在本 VLAN 内部转发，不会泛洪到其他 VLAN，减少带宽与设备资源消耗。同时也可以把不同业务设备逻辑分组，提升网络安全性，方便运维管理。不同 VLAN 之间默认二层不能互相访问，需要三层设备才能实现互通**


### **<span style="color:#3498db">创建vlan</span>**

首先，登入思科交换机后，是**非特权模式**，需要使用**enable**进入**特权模式**，如此才能进行一些相关配置。

进入特权模式后，输入**config**进入配置模式，这里就可以进行vlan的创建了。

```ini
enable
config

# 划分vlan标签
vlan 10

# 给vlan起个便于理解的名字
name office

# 退出vlan配置
exit

查看创建vlan的情况
show  vlan  brief

```


### **<span style="color:#3498db">vlan标签的作用</span>**

创建vlan时，后面跟的**数字**就是vlan的标签，但实际，即便没有划分vlan，所有设备的数据都有一个默认的标签**vlan 1**

在没有划分vlan限制二层广播域的情况下，所有**vlan1**都是可以泛洪到没有划分vlan标签的全域的。

而在划分vlan标签后，它们默认只能在**本标签**的vlan内泛洪


### **<span style="color:#3498db">端口与vlan标签</span>**

**端口：**即交换机的物理接口，或者无线接口，在打上vlan标签后，从该端口进入的数据都会被打上对对应的vlan标签

**端口的两种模式：**端口有两种模式，分别为**access**和**trunk**，**access**一次只能打上一个标签，**trunk**则可以同时通过多个标签。**access**一般用于连接终端设备，**trunk**则一般用于与路由器（单臂路由：一个物理接口接收多个vlan的流量）或者另一台交换机的trunk口连接。

**本征 VLAN（Native‑VLAN）：Trunk 接口的特殊属性**

1. 收到**带标签帧**：检查该 VLAN 是否在 Trunk 允许放行列表，允许则转发，不允许直接丢弃。
2. 收到**无标签 Untagged 帧**：Trunk 口会将该帧划分给接口配置的本征 VLAN。
3. 发送帧从 Trunk 口出去：
   - 属于本征 VLAN 的流量：**剥离 VLAN 标签，以无标签帧发出**；
   - 其他 VLAN 流量：保留原有 VLAN 标签发出。
4. 注意：**链路两端 Trunk 的本征 VLAN 必须配置一致**。
如果两端本征 VLAN 不一致，报文不会直接丢弃；无标签帧会被归入对端的本征 VLAN，造成 VLAN 错乱、业务异常。开启本征 VLAN 校验功能时才会丢弃报文。

**双标签攻击：**攻击者将数据打上**两个vlan**，外层是**本征vlan**，用于在发送时被剥离，里层是想要**横向移动**的vlan，如vlan20，这样在发送时，trunk口发现标签是本征vlan，就会直接剥离标签然后发送，对面交换机则收到一个被剥离外层标签后带vlan20标签的数据帧，将其发送到vlan20里，导致横向移动成功。所以在trunk口，最好划分一个不常见的本征vlan。

### **<span style="color:#3498db">端口模式划分实操指令</span>**

```ini
# 进入配置模式
config

# 选择交换机接口0/0
interface gigabitEthernet 0/0

# 设置access模式
switchport mode access

# 设置标签
switchport access vlan10

# 退出
exit


# 选择交换机接口0/1
interface gigabitEthernet 0/1

# 设置trunk模式的加密方法为802.1q
switchport trunk encapsulation dot1q

# 设置模式为trunk
switchport mode trunk

# 设置允许通过的vlan
switchport trunk  allowed vlan 10,20

# 设置本征vlan
switchport trunk  native vlan 99

# 退出
exit
```

### **<span style="color:#3498db">网关</span>**

所有 **VLAN 划分、端口打标签**都属于二层，不同 VLAN 二层相互隔离；跨网段通信还是要依赖三层 IP 网关。当主机判断目标 IP 不在本地网段，主机需要把数据包交给网关转发。主机首先在本 VLAN 内**泛洪 ARP 广播**，请求网关 IP 对应的 MAC 地址；网关收到 ARP 请求后回复**网关自身的 MAC 地址**给主机。主机拿到网关 MAC，封装二层帧将 IP 报文发给网关；网关再查询路由，后续再解析目标地址，完成跨网段转发

#### 配置网关

```ini
# 三层交换机配置网关，三层交换机的网关也叫做SVI
# 开启三层网关
ip routing

# 指定对应的vlan设置其网关（SVI），给网关ip地址
interface vlan 10
ip address 192.168.10.1 255.255.255.0
# 开启端口
no shutdown

# 路由物理端口直接设置网关
interface GigabitEthernet0/0    # 进入接口，如G0/0
 ip address 192.168.1.1 255.255.255.0   # 接口IP，PC网关就是192.168.1.1
 no shutdown                     # 启用端口
exit

# 单臂路由，子接口设置网关
# 物理接口不设置ip
interface GigabitEthernet0/0 
no ip address
exit

# 子接口作为网关，承接10的流量
interface GigabitEthernet0/0.10 
encapsulation dot1Q 10
ip address 192.168.10.1 255.255.255.0


```
