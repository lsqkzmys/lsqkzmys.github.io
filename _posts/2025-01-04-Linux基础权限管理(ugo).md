# Linux 用户权限基础：常用命令与文件

权限管理是 Linux 系统里最基础也最重要的技能之一。

## 1. 查看权限（最常用）

### ls 命令

```bash
ls -l          # 查看权限（推荐）
ls -la         # 显示所有文件（包括隐藏的）
ls -ld /目录名   # 只看目录本身的权限
ls -lh         # 显示文件大小更友好（K、M单位）
```

**输出示例(ls -l)**：
```
drwxr-xr-x  2 user group 4096 7月 17 10:00 mydir
-rw-r--r--  1 user group  123 7月 17 10:00 file.txt
```

## 2. 修改权限 —— chmod（最重要命令）

### 方法一：符号方式

```bash
chmod u+x 文件名          # 所有者增加执行权限
chmod g+w 文件名          # 所属组增加写权限
chmod o-r 文件名          # 其他人移除读权限
chmod a+x 文件名          # 所有人增加执行权限
```

**同时修改多个用户的多个权限**：

```bash
chmod u+rwx,g+rx,o-rwx 文件名
```

### 方法二：数字方式


用三位数字分别表示所有者、所属组、其他用户的权限，每位数字是对应权限值的和。
计算规则：r=4, w=2, x=1

7 = 4+2+1 = rwx
6 = 4+2 = rw-
5 = 4+1 = r-x
4 = 4 = r--
0 = 无权限

```bash
chmod 755 文件名     # 最常用：rwxr-xr-x
chmod 644 文件名     # 最常用：rw-r--r--
chmod 600 文件名     # 只有所有者能读写
chmod 700 文件名     # 只有所有者能读写执行
```

**递归修改文件夹**：

```bash
chmod -R 755 /文件夹路径
```

## 3. 修改所有者和所属组

```bash
# 修改所有者
chown 用户名 文件名
chown 用户名:组名 文件名        # 同时改所有者和组

# 修改所属组
chgrp 组名 文件名
chown :组名 文件名

# 递归修改文件夹
chown -R 用户名:组名 /文件夹路径
```

## 4. 常用查询命令

```bash
id                    # 当前用户的 UID、GID 和组
id 用户名             # 查看指定用户
groups                # 当前用户所在组
whoami                # 当前用户名
```

## 5. 重要配置文件

| 文件路径           | 作用                     | 查看命令                    |
|--------------------|--------------------------|-----------------------------|
| /etc/passwd        | 所有用户信息             | cat /etc/passwd             |
| /etc/group         | 所有用户组信息           | cat /etc/group              |
| /etc/shadow        | 用户密码（需 root）      | sudo cat /etc/shadow        |
| /etc/sudoers       | sudo 权限配置            | sudo visudo                 |

## 6. 实用示例

```bash
# 新建脚本并给执行权限
touch myscript.sh
chmod +x myscript.sh

# 网站目录权限设置
chown -R www-data:www-data /var/www/html
chmod -R 755 /var/www/html

# 保护 SSH 私钥
chmod 600 ~/.ssh/id_rsa
```
