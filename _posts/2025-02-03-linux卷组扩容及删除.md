### <span style="color:#3498db">卷组扩容</span>

**现状**： ![mm](/assets/img/2026-08-03-16-13-33.png)

可以看到无论是逻辑卷大小，还是文件系统大小，lv_exa都是2.8G左右，下面进行扩容

**思路：** <span style="color:#27ae60">创建空白分区 -> 将空白分区物理卷初始化 -> 利用新物理卷扩容卷组 -> 逻辑卷扩容 -> 文件系统适应 </span>

**步骤：**

1. 将磁盘剩下的空间划分分区或者直接用空闲的分区 `sudo parted /dev/sdb` -> `mkpart primary 6GB 100%FREE` (如果创建错误的分区，可以通过rm [p查看到的分区序号] 来删除)
        ![mm](/assets/img/2026-08-03-16-35-09.png)

2. 分区物理卷初始化，并扩容到卷组 `sudo pvcreate /dev/sdb3` -> `sudo vgextend /dev/vg_data /dev/sdb3`  
        ![mm](/assets/img/2026-08-03-16-36-06.png)

3. `sudo lvextend -L +3G /dev/vg_data/lv_exa` （在扩容前，先确定卷组空余空间是否足够）
        ![mm](/assets/img/2026-08-03-16-38-39.png)

4. `sudo resize2fs /dev/vg_data/lv_exa`（如果是xfs文件系统，用`sudo xfs_growfs /data1(挂载的目录)` ）
        ![mm](/assets/img/2026-08-03-16-39-43.png)
        ![mm](/assets/img/2026-08-03-16-43-54.png)

### <span style="color:#3498db">逻辑卷,卷组,物理卷删除</span>

**思路：** <span style="color:#27ae60">取消挂载 -> 删除配置 -> 删除逻辑卷 -> 删除卷组 -> 删除物理卷</span>

**步骤：**

1. 取消挂载，并删除/etc/fstab的配置 `sudo umount /dev/vg_data/lv_exa` `sudo vim /etc/fstab`
        ![mm](/assets/img/2026-08-03-16-53-08.png)

2. 移除用卷组创建的所有逻辑卷 `lvremove /dev/vg_data/lv_exa`
        ![mm](/assets/img/2026-08-03-16-57-27.png)

3. 移除卷组 `sudo vgremove vg_data`
        ![mm](/assets/img/2026-08-03-16-58-47.png)

4. 移除物理卷 `sudo pvremove /dev/sdb2 /dev/sdb3`
        ![mm](/assets/img/2026-08-03-17-00-18.png)
