## **<span style="color:#3498db">静态路由</span>**

```ini

#目标ip为对应网段，下一跳应该去往哪里，默认优先级大于动态
ip route 192.168.10.0 255.255.255.0 23.14.2.157

```

## **<span style="color:#3498db">动态路由</span>**

**即动态变更，非一成不变的路由。常见的有两种动态路由：RIP和OSPF。**

### **<span style="color:#3498db">RIP</span>**

特殊名词：

- **跳数：**RIP 协议使用的度量值，代表数据包从源网络去往目标网络，**途中需要穿越的路由器数量**，如A-B-C就是一跳，C-D-E-F就是两跳
- **环路：**因为RIP是固定时间（默认30s）更新，当网络出错时，可能造成信息不同步的故障。

如r2知道要前往192网段需要经过r1，这时192网段出错，r1还没有来得及将信息同步出去，r2的消息就来了，它有去往192的路线，1跳，于是r1更新自己的路由，去往192，2跳。r2收到消息，r1去往192要2跳，于是更新路由，前往192，3跳。于是一直循环，直到跳数达到16，循环才结束。可以通过抑制计时器，即在发现坏路由时，一定时间内不接收对应路由更新来解决

**RIP特点：**根据固定时间更新路由表，按跳数来决定最优路线，当跳数达到16跳时即认为不可达。可能造成环路问题，不适用于大型网络。

```ini
# 指定动态路由类型为rip
router rip

#指定rip版本
version 2

#关闭网段自动汇总
no auto-summary

#宣告网段
network 192.168.12.0
network 192.168.10.0
network 192.168.20.0
```

### **<span style="color:#3498db">OSPF</span>**

特殊名词：

- **LSA**：链路状态通告，类似目录，描述路由器链路、网段信息

- **LSDB**：链路状态数据库，实际保存的数据，同一区域内所有路由器 LSDB 完全一致

- **选举**：选举DR/BDR；DR负责收集LSA，BDR作为备份，减少邻居邻接关系数量，降低网络报文开销。优先看优先级，优先级相同再看router-id，两者都是越大越优先。优先级为0默认不参与选举，成为普通成员。

- **区域**：Area，用来分割大的OSPF网络，减少计算压力；**Area0（骨干区域）**是核心，所有非骨干区域必须和骨干区域相连

- **开销(cost)**：参考带宽 ÷ 接口带宽。默认参考带宽：100Mbps。OSPF不依靠跳数来决定下一跳，而是根据开销来决定，越小的开销优先级越高。开销不足1，升为1，其它小数如3.7，则直接向下取整为3。

整体流程概览：

1. 建立邻居：路由器互发 Hello 包，参数匹配后形成邻居关系；多路访问网络选举 DR、BDR
2. 交换 LSA：两台路由器交换 LSA，同步各自链路信息
3. 存入 LSDB：收到 LSA 存入链路状态数据库，同一区域所有路由器 LSDB 保持一致
4. 运行 SPF 算法：以自己为根，基于 LSDB 计算最短无环路径
5. 生成路由表：把算出的最优路径放进路由表，指导数据包转发

**OSPF特点：**实时更新，收敛速度更快，根据开销计算最优路径，没有最大16跳的限制，适合大型网络，但配置更为复杂

```ini

#设置环回接口作为router-id
interface loopback 0
ip address 1.1.1.1 255.255.255.255

#设置路由类型，设置OSPF的进程id（只OSPF这个类型的，不是总体进程的id）
router ospf 1

#设置router-id
router-id 1.1.1.1

#宣告网段和区域
network 10.0.0.4 0.0.0.3 area 0
```
